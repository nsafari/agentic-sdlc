The 9-Step Software Factory

From human intent to live software in nine automated steps.

01

Describe

User explains the need in natural language.

02

Detect

AI determines the appropriate application type: Web or Android.

03

Provision

Create a GitHub repository and configure the CI/CD workflow.

04

Engineer

OpenCode + oh-my-opencode implement the application according to the requirements and software engineering principles.

05

Validate

Build, lint, test and security validation happen before release.

06

Release

The validated application is tagged, released and deployed.

07

Store

When lightweight persistence is appropriate, Google Sheets can be used as the data store.

08

Iterate

The user requests changes in natural language and the software evolves.

09

Meter

AI usage is metered through tokens; when the included usage is exhausted, the user can purchase additional usage.
